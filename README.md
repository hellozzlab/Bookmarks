# Bookmarks

一个简洁的个人书签管理页面，用来收藏常用网站、整理资源和查找灵感。

使用原生 HTML、CSS 和 JavaScript 构建，所有页面代码集中在一个 `index.html` 文件中，无需安装依赖或配置后端，可部署到 GitHub Pages。

## 功能

- **书签管理**：添加、编辑和删除书签，记录网址、名称、描述与标签。
- **标签筛选**：按标签查看书签，并显示各标签下的书签数量。
- **关键词搜索**：搜索名称、网址、描述和标签，可与当前标签筛选配合使用。
- **归档整理**：将暂时不用的书签移入归档，或恢复到首页。
- **备份与恢复**：导出 JSON 备份文件，并通过导入恢复数据。
- **主题切换**：支持浅色与深色模式，记住上次选择。
- **本地保存**：书签保存在当前浏览器的 `localStorage` 中，无需注册账号。
- **响应式布局**：适配桌面与手机屏幕。

## 使用方法

1. 打开部署后的页面。首次使用会显示一组示例书签。
2. 点击右下角的 **＋**，填写网址和网站名称；描述与标签可选，多个标签用中文或英文逗号分隔。
3. 点击顶部标签筛选书签，点击 **All** 恢复显示当前视图下的全部标签。
4. 点击书签名称，在新标签页打开网站；通过书签右上角的 **…** 菜单编辑、归档或删除。
5. 点击页面右下角的 **…**，使用以下功能：

| 菜单 | 功能 |
| --- | --- |
| Search | 在当前首页或归档视图中搜索书签 |
| Home | 返回首页并清除搜索与标签筛选 |
| Import | 从 JSON 备份恢复书签 |
| Backup | 下载全部书签的 JSON 备份，包含已归档条目 |
| Archive | 切换归档视图 |

点击主题按钮即可切换浅色与深色模式。当前页面界面为英文。

## 数据与备份

书签修改只保存在当前浏览器中，不会自动提交到 GitHub，也不会在不同设备或浏览器之间同步。其他访问者使用各自浏览器中的数据。

清除网站数据、更换浏览器或更换访问域名后，原有书签可能不再可用。建议定期通过 **Backup** 下载备份，在新环境中通过 **Import** 恢复。

**导入会替换当前全部书签，而不是合并。** 导入前会显示确认提示，建议先备份现有数据。当前支持项目导出的 JSON 备份，不支持直接导入浏览器导出的 HTML 书签文件。主题偏好不包含在书签备份中。

## 部署到 GitHub Pages

全程可在 GitHub 网页上完成：

1. 将 `index.html` 上传到仓库根目录。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 下，将 **Source** 设为 **Deploy from a branch**。
4. 选择存放文件的分支（通常为 `main`），目录选择 **/(root)**，点击 **Save**。
5. 等待部署完成，通过 Pages 设置页面显示的网址访问。

使用 GitHub Free 时，仓库需要设为公开仓库才能启用 GitHub Pages。

部署步骤参考：[GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 技术说明

- 原生 HTML、CSS、JavaScript，无前端框架和构建步骤。
- 使用 `localStorage` 保存书签与主题偏好。
- 使用 Google Fonts 提供的 Material Symbols Rounded 图标字体。
- 网站图标尝试从对应网站的 `/favicon.ico` 加载，失败时显示默认图标。

图标字体与网站图标需要网络连接；项目没有自建服务端、账号系统或云端同步功能。
